\# Staff Directory Web



A clean, responsive frontend staff directory website built with vanilla HTML, CSS, and JavaScript. It allows visitors to browse team members, filter by department, search by name or role, and view detailed profiles in an interactive modal.



[click to view](https://minshida-latheef.github.io/staff-directory-web/)



\## Features



\- \*\*Responsive Card Grid:\*\* Automatically adapts to desktop, tablet, and mobile screens using CSS Grid.

\- \*\*Department Filtering:\*\* Filter staff members by department (`All`, `Leadership`, `Engineering`, `Design`, `Marketing`).

\- \*\*Real-Time Search:\*\* Instant search filtering by staff member name or job title.

\- \*\*Profile Modal:\*\* Click \*\*View Profile\*\* on any card to open a modal with the member's full bio and a direct email link.

\- \*\*Data-Driven Rendering:\*\* Staff profiles are stored in a centralized JavaScript array for easy updates without editing HTML.
